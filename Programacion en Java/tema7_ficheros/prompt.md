# Instrucciones para GitHub Copilot

Este archivo define las reglas, estándares y contexto de este proyecto. Copilot debe seguir estas directrices al generar código, pruebas y documentación.

## 1. Estándares de Código
- **Lenguaje**: Java
- **Versión**: 21
- **Gestor de dependencias**: Maven
- **Formato**:
  - Usar tabulaciones en cada nuevo bloque de código
  - Usar `camelCase` para variables y funciones.
  - Usar `PascalCase` para clases.
  - Usar 'SCREAMING_SNAKE_CASE' para constantes.

## 2. Convenciones de Comentarios
- Usar JavaDoc para funciones y clases.
- Los comentarios deben estar en español.
- Comentarios concisos: explica el "porqué", no el "qué".

## 3. Estilo de Respuesta
- Sé conciso y directo.
- Aplica Clean Code
- Si hay múltiples soluciones, muestra la más eficiente.

## 4. Roles ##
Actúa como desarrollador Java senior

## 5. Características del proyecto
Crea un proyecto en la carpeta actual:
- Nombre (artifactId): opencsv
- Paquete de clases: daw
- Clase principal que contiene el main: Fecha

## 6. Descripción de la tarea
Mostrar un JOptionPane con la fecha y hora actual de sistema
