1. Leer JSON con Jackson

📦 Dependencia (Maven)

<dependency>
  <groupId>com.fasterxml.jackson.core</groupId>
  <artifactId>jackson-databind</artifactId>
  <version>2.17.0</version>
</dependency>

📄 Ejemplo JSON

[
  {"nombre":"Ana","edad":20},
  {"nombre":"Luis","edad":25}
]

👤 Clase Java

public class Persona {
    public String nombre;
    public int edad;
}

📖 Leer JSON

import com.fasterxml.jackson.databind.ObjectMapper;
import java.io.File;
import java.util.List;

ObjectMapper mapper = new ObjectMapper();

List<Persona> lista = mapper.readValue(
    new File("personas.json"),
    mapper.getTypeFactory().constructCollectionType(List.class, Persona.class)
);

for (Persona p : lista) {
    System.out.println(p.nombre + " " + p.edad);
}

🔹 2. Leer CSV con Jackson

📦 Dependencia extra

<dependency>
  <groupId>com.fasterxml.jackson.dataformat</groupId>
  <artifactId>jackson-dataformat-csv</artifactId>
</dependency>

📄 CSV

nombre,edad
Ana,20
Luis,25

📖 Leer CSV

import com.fasterxml.jackson.dataformat.csv.*;

CsvMapper mapper = new CsvMapper();

CsvSchema schema = CsvSchema.emptySchema().withHeader();

MappingIterator<Persona> it = mapper.readerFor(Persona.class)
        .with(schema)
        .readValues(new File("personas.csv"));

List<Persona> lista = it.readAll();

🔹 3. Mostrar datos en JTable

🧱 Crear tabla básica

import javax.swing.*;
import javax.swing.table.DefaultTableModel;

String[] columnas = {"Nombre", "Edad"};

DefaultTableModel modelo = new DefaultTableModel(columnas, 0);

for (Persona p : lista) {
    modelo.addRow(new Object[]{p.nombre, p.edad});
}

JTable tabla = new JTable(modelo);

JFrame ventana = new JFrame("Tabla");
ventana.add(new JScrollPane(tabla));
ventana.setSize(300, 200);
ventana.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
ventana.setVisible(true);

🔹 4. Generar JSON

✍️ Escribir JSON desde lista

ObjectMapper mapper = new ObjectMapper();

mapper.writerWithDefaultPrettyPrinter()
      .writeValue(new File("salida.json"), lista);

🔹 5. Generar CSV

CsvMapper mapper = new CsvMapper();

CsvSchema schema = mapper.schemaFor(Persona.class).withHeader();

mapper.writer(schema)
      .writeValue(new File("salida.csv"), lista);
🔹 6. Caso típico de examen (muy importante)

Te pueden pedir algo como:

👉 “Lee un JSON, muéstralo en JTable y guárdalo en CSV”

🧠 Pasos rápidos:

Crear clase (Persona)
Leer JSON → List<Persona>
Crear DefaultTableModel
Rellenar JTable
Usar CsvMapper para guardar

🔹 7. Tips clave (esto te salva el examen)

⚠️ Los nombres del JSON deben coincidir con atributos
⚠️ Usa public o getters/setters
⚠️ Para listas → constructCollectionType
⚠️ CSV necesita .withHeader()
⚠️ JTable siempre con DefaultTableModel

🔹 8. Plantilla mental rápida

Si te bloqueas, recuerda:

Archivo → Mapper → Lista → JTable → Guardar
