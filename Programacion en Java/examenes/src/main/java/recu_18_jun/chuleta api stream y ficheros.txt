CLASE MODELO (POJO) — Persona.java
----------------------------------------------------------------

Lo que necesita para funcionar con OpenCSV Y Jackson:
  - Constructor VACÍO obligatorio (Jackson lo necesita)
  - Constructor parametrizado
  - Getters y setters para TODO
  - equals/hashCode por id
  - toString
  - Anotaciones @CsvBindByName en cada atributo

package modelos;

import com.opencsv.bean.CsvBindByName;
import com.opencsv.bean.CsvDate;
import java.time.LocalDate;
import java.util.Objects;

public class Persona {

    @CsvBindByName(column = "id")
    private long id;

    @CsvBindByName(column = "nombre")
    private String nombre;

    @CsvBindByName(column = "apellido")
    private String apellido;

    @CsvBindByName(column = "email")
    private String email;

    @CsvBindByName(column = "genero")
    private String genero;

    @CsvDate("dd-MM-yyyy")              // ← formato de fecha en el CSV
    @CsvBindByName(column = "fecha_nacimiento")
    private LocalDate fechaNacimiento;  // ← tipo LocalDate, no String

    @CsvBindByName(column = "jubilado")
    private boolean jubilado;

    @CsvBindByName(column = "ciudad")
    private String ciudad;

    public Persona() {}   // ← OBLIGATORIO para Jackson

    public Persona(long id, String nombre, String apellido, String email,
                   String genero, LocalDate fechaNacimiento,
                   boolean jubilado, String ciudad) {
        this.id = id;
        this.nombre = nombre;
        this.apellido = apellido;
        this.email = email;
        this.genero = genero;
        this.fechaNacimiento = fechaNacimiento;
        this.jubilado = jubilado;
        this.ciudad = ciudad;
    }

    public long getId() { return id; }
    public void setId(long id) { this.id = id; }
    public String getNombre() { return nombre; }
    public void setNombre(String nombre) { this.nombre = nombre; }
    public String getApellido() { return apellido; }
    public void setApellido(String apellido) { this.apellido = apellido; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    public String getGenero() { return genero; }
    public void setGenero(String genero) { this.genero = genero; }
    public LocalDate getFechaNacimiento() { return fechaNacimiento; }
    public void setFechaNacimiento(LocalDate f) { this.fechaNacimiento = f; }
    public boolean isJubilado() { return jubilado; }
    public void setJubilado(boolean jubilado) { this.jubilado = jubilado; }
    public String getCiudad() { return ciudad; }
    public void setCiudad(String ciudad) { this.ciudad = ciudad; }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Persona)) return false;
        Persona p = (Persona) o;
        return id == p.id;
    }

    @Override
    public int hashCode() { return Objects.hash(id); }

    @Override
    public String toString() {
        return "Persona{id=" + id + ", nombre=" + nombre
             + ", apellido=" + apellido + ", email=" + email
             + ", genero=" + genero + ", fechaNacimiento=" + fechaNacimiento
             + ", jubilado=" + jubilado + ", ciudad=" + ciudad + "}";
    }
}

⚠ Los nombres en column = "..." deben coincidir EXACTAMENTE
  con las cabeceras del CSV (copia y pega del CSV para estar seguro)

⚠ Para boolean usa isJubilado() como getter, no getJubilado()
  Jackson y OpenCSV lo esperan así

⚠ @CsvDate solo va en atributos LocalDate, no en Strings

LEER CSV — LeerCSV.java
----------------------------------------------------------------

package ficheros;

import com.opencsv.bean.CsvToBeanBuilder;
import java.io.FileReader;
import java.io.IOException;
import java.util.List;
import modelos.Persona;

public class LeerCSV {

    public static List<Persona> leer(String ruta) throws IOException {
        try (FileReader reader = new FileReader(ruta)) {
            return new CsvToBeanBuilder<Persona>(reader)
                    .withType(Persona.class)
                    .withIgnoreLeadingWhiteSpace(true)
                    .build()
                    .parse();
        }
    }
}

Cómo funciona:
  - FileReader abre el fichero
  - CsvToBeanBuilder lee cada línea y la convierte en un objeto Persona
    usando las anotaciones @CsvBindByName
  - withIgnoreLeadingWhiteSpace(true) evita errores por espacios
  - try-with-resources cierra el fichero automáticamente al acabar
  - El método lanza IOException → en el main se envuelve en try-catch

Cómo llamarlo desde el main:
  List<Persona> personas = null;
  try {
      personas = LeerCSV.leer("personas.csv");
  } catch (IOException e) {
      System.out.println("Error al leer el fichero: " + e.getMessage());
  }

ESCRIBIR JSON — EscribirJSON.java
----------------------------------------------------------------

package ficheros;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.SerializationFeature;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;
import java.io.File;
import java.io.IOException;
import java.util.List;
import modelos.Persona;

public class EscribirJSON {

    public static void escribir(List<Persona> personas, String ruta) throws IOException {
        ObjectMapper mapper = new ObjectMapper();
        mapper.registerModule(new JavaTimeModule());
        mapper.configure(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS, false);
        mapper.writerWithDefaultPrettyPrinter().writeValue(new File(ruta), personas);
    }
}

Cómo funciona línea a línea:
  ObjectMapper mapper = new ObjectMapper();
    → el objeto principal de Jackson, hace toda la serialización

  mapper.registerModule(new JavaTimeModule());
    → sin esto Jackson no sabe manejar LocalDate y lanza error

  mapper.configure(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS, false);
    → sin esto escribe la fecha como número [2026,3,21]
    → con false escribe "1985-03-21" en formato legible

  mapper.writerWithDefaultPrettyPrinter().writeValue(new File(ruta), personas);
    → writerWithDefaultPrettyPrinter() → JSON indentado y legible
    → writeValue() → escribe la lista en el fichero

Cómo llamarlo desde el main:
  try {
      EscribirJSON.escribir(jubiladas, "jubiladas.json");
  } catch (IOException e) {
      System.out.println("Error al escribir el fichero: " + e.getMessage());
  }

⚠ El fichero JSON se crea en la raíz del proyecto (donde está el pom.xml)
⚠ Si el fichero ya existe lo sobreescribe

LEER FICHERO MANUALMENTE (sin OpenCSV)
----------------------------------------------------------------

Si el examen no pide OpenCSV puedes hacerlo con BufferedReader:

public static List<Persona> leer(String ruta) {
    List<Persona> lista = new ArrayList<>();
    try (BufferedReader br = new BufferedReader(new FileReader(ruta))) {
        String linea;
        br.readLine(); // saltar cabecera
        while ((linea = br.readLine()) != null) {
            String[] partes = linea.split(",");
            Persona p = new Persona(
                Long.parseLong(partes[0].trim()),
                partes[1].trim(),
                partes[2].trim()
                // ... etc según columnas del CSV
            );
            lista.add(p);
        }
    } catch (IOException e) {
        e.printStackTrace();
    }
    return lista;
}

⚠ Tienes que parsear cada campo manualmente
⚠ Las fechas hay que convertirlas: LocalDate.parse(partes[5].trim())

ESCRIBIR FICHERO MANUALMENTE (sin Jackson)

public static void escribir(Map<String, Integer> map, String ruta) {
    try (FileWriter fw = new FileWriter(ruta)) {
        for (Map.Entry<String, Integer> e : map.entrySet()) {
            fw.write(e.getKey() + "," + e.getValue() + "\n");
        }
    } catch (IOException e) {
        e.printStackTrace();
    }
}

⚠ FileWriter sobreescribe el fichero por defecto
  new FileWriter(ruta, true) → modo append (añade al final)

API STREAM — PATRONES QUE MÁS CAEN
----------------------------------------------------------------

Los streams siguen siempre esta estructura:
  lista.stream()
       .operacionIntermedia()   // filter, map, sorted, limit...
       .operacionIntermedia()   // se pueden encadenar
       .operacionTerminal();    // collect, forEach, count...

-- PATRÓN 1: filter + map + collect → Set de Strings --

Set<String> correos = personas.stream()
    .filter(p -> p.getCiudad().equals("Los Angeles"))
    .map(p -> p.getEmail())
    .collect(Collectors.toSet());

Léelo: "quédate con las de Los Angeles → coge su email → mete en Set"


-- PATRÓN 2: groupingBy + counting → Map<String, Long> --

Map<String, Long> conteo = personas.stream()
    .collect(Collectors.groupingBy(
        p -> p.getGenero(),
        Collectors.counting()
    ));

Léelo: "agrupa por género y cuenta cuántas hay en cada grupo"
Resultado: {"Female"=320, "Male"=280}


-- PATRÓN 3: groupingBy solo → Map<String, List<Persona>> --

Map<String, List<Persona>> grupos = personas.stream()
    .collect(Collectors.groupingBy(p -> p.getGenero()));

Léelo: "agrupa por género guardando la lista completa de cada grupo"
Resultado: {"Female"=[Persona1, Persona2...], "Male"=[...]}


-- PATRÓN 4: filter + filter + sorted + collect → List ordenada --

List<Persona> jubiladas = personas.stream()
    .filter(p -> p.isJubilado())
    .filter(p -> p.getGenero().equals("Female"))
    .sorted(Comparator.comparing(p -> p.getFechaNacimiento()))
    .collect(Collectors.toList());

Léelo: "jubiladas → solo femeninas → ordena por fecha → a lista"

Orden inverso:
    .sorted(Comparator.comparing(p -> p.getFechaNacimiento()).reversed())


-- PATRÓN 5: map + collect → extraer campo a lista --

List<String> nombres = personas.stream()
    .map(p -> p.getNombre())
    .collect(Collectors.toList());


-- PATRÓN 6: filter + count → contar elementos --

long mayoresDe25 = personas.stream()
    .filter(p -> p.getEdad() > 25)
    .count();


-- OTROS OPERADORES ÚTILES --

.limit(10)                                    // solo los primeros 10
.distinct()                                   // elimina duplicados
.sorted()                                     // orden natural
.sorted(Comparator.comparing(p -> p.getNombre()))  // orden por campo
.anyMatch(p -> p.isJubilado())                // ¿alguno cumple? → boolean
.allMatch(p -> p.isJubilado())                // ¿todos cumplen? → boolean
.findFirst()                                  // primer elemento

public class Programa {

    public static void main(String[] args) {

        // 1. Leer CSV con try-catch
        List<Persona> personas = null;
        try {
            personas = LeerCSV.leer("personas.csv");
        } catch (IOException e) {
            System.out.println("Error al leer el fichero: " + e.getMessage());
        }

        // 2. Operaciones Stream
        System.out.println("Correos en Los Angeles:");
        System.out.println(OperacionesStream.correosEnLosAngeles(personas));

        System.out.println("\nConteo por género:");
        System.out.println(OperacionesStream.contarPorGenero(personas));

        System.out.println("\nAgrupados por género:");
        System.out.println(OperacionesStream.agruparPorGenero(personas));

        // 3. Generar lista filtrada
        List<Persona> jubiladas =
            OperacionesStream.jubiladasFemeninasOrdenadasPorFecha(personas);

        System.out.println("\nJubiladas femeninas:");
        jubiladas.forEach(p -> System.out.println(p));

        // 4. Escribir JSON con try-catch
        try {
            EscribirJSON.escribir(jubiladas, "jubiladas.json");
            System.out.println("\nFichero generado correctamente.");
        } catch (IOException e) {
            System.out.println("Error al escribir el fichero: " + e.getMessage());
        }
    }
}

⚠ personas se declara fuera del try para poder usarla después
⚠ Cada llamada a ficheros va en su propio try-catch

----------------------------------------------------------------

⚠ Olvidar el constructor vacío en la clase modelo
  → Jackson no puede crear el objeto y lanza error

⚠ @CsvDate solo va en atributos LocalDate, no en Strings

⚠ El nombre en @CsvBindByName debe coincidir exactamente
  con la cabecera del CSV (copia y pega del CSV para estar seguro)

⚠ Olvidar registerModule(new JavaTimeModule()) en EscribirJSON
  → Jackson lanza error con LocalDate

⚠ Olvidar WRITE_DATES_AS_TIMESTAMPS = false
  → Las fechas salen como [2026, 3, 21] en vez de "2026-03-21"

⚠ El fichero CSV debe estar en la raíz del proyecto (donde pom.xml)
  para que la ruta "personas.csv" funcione sin ruta absoluta

  → no podrás usarla fuera, declárala antes como null
